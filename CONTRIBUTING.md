# Contributing to Game Capture

Thanks for helping improve Game Capture.

## Pull requests

- Fork the repo and create a feature branch.
- Keep changes focused and include tests where practical.
- Exercise the affected application workflows. Describe actual application
  testing separately from build, lint and other gates, as required by
  [AGENTS.md](AGENTS.md).
- Open a PR explaining the problem, change and validation.

## Contributor License Agreement (required)

Read the [CLA](CLA.md), then follow the CLA Assistant signing link on your pull
request. You can also open the [project's signing page](https://cla-assistant.io/steveseguin/game-capture).
Sign using your own GitHub account. The `license/cla` check must pass before a
normal pull-request merge into `main`; repository administrators retain an
explicit override.

This is the existing shared agreement used by VDO.Ninja. Contributors retain
copyright and grant Steve Seguin broad, perpetual, irrevocable rights to use,
modify, distribute and sublicense their contributions on any licensing terms,
including MIT and proprietary/commercial terms. It includes moral-rights
provisions. It is a license grant, not a copyright-assignment agreement.

The exact hosted agreement is copied in [CLA.md](CLA.md). One acceptance covers
past, present and future contributions under the applicable agreement; material
changes require renewed acceptance. For company-owned contributions, follow the
agreement's authorized-company-signature instructions. Identify coauthors and
third-party code, assets, sources and licenses in your PR.

If hosted signing is unavailable, the agreement permits sending a signed copy
to <steve@seguin.email>. Arrange this with the maintainer; a PR checkbox or Git
commit sign-off alone is not a CLA signature.

## Maintainer review

Confirm coverage for every rights holder, including employer/client ownership
and coauthors. Keep acceptance records and the exact accepted agreement revision;
keep privately supplied records private. An administrator override must not be
used as evidence that an unsigned contributor accepted the agreement.

Adding this file does not obtain rights from unsigned past contributors or
replace third-party licenses. The current [AGPL license](LICENSE) remains in
place. Audit all affected rights before relicensing a release.

See [CLA Assistant configuration](.github/cla-assistant/README.md) for the linked
Gist, webhook and required-check details.

## Code of conduct

Be respectful and constructive in discussions and reviews.
