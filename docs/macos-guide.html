Game Capture on Mac

Share an app window or camera through VDO.Ninja, then watch it in a browser or bring it into OBS.

Download Mac 0.2.65 Beta 3 Release notes, source & checksums

Requires an Apple Silicon (M-series) Mac and macOS 14.2+. Intel Macs are not supported. This Mac release is experimental; Windows remains the stable version.

What has been tested in this beta?
  • Packaged workflows passed on an M1 with macOS 26.4.1.
  • Fresh macOS 14.8.9 ARM64 VMs passed bounded startup and x264 workflows.
  • Physical minimum-OS, permissions and device transitions still need broader qualification.

1. Install and allow access

  1. Download the Mac ZIP, extract it, and drag Game Capture.app into Applications.
  2. Open the app from Applications. Confirm the macOS Open prompt if shown.
  3. For window capture, click Screen Recording… in Game Capture. Allow the app in the settings window that opens.
  4. Restart Game Capture if macOS asks you to.
  5. When you first go live with a camera or microphone, allow its separate permission prompt, then try Go Live again.
Where are these permissions in System Settings?

Open System Settings → Privacy & Security.

  • Screen & System Audio Recording allows window capture. Some macOS versions call it Screen Recording.
  • Camera and Microphone have separate controls. Allow only the sources you want to share.

2. Send your first stream

  1. Open the app or game you want to share and keep its window visible.
  2. In Game Capture, choose Video Source → Window. Click Refresh, use the source filter if needed, and select the window. Check the local preview.
  3. Enter a unique Stream ID, or paste the VDO.Ninja publishing URL supplied by your director. Keep any required password consistent with your viewing or room setup.
  4. Open Show advanced settings to choose audio and encoding. A starting point is H.264, Apple VideoToolbox, 1280×720, 30 FPS, 4,000 kbps.
  5. Click Go Live. After streaming starts, use Copy Link to share the generated viewer URL. Open that link in a browser to verify picture and sound.
  6. Click Stop when finished. Stop before changing settings that are locked during streaming.

Camera / Webcam

Choose Camera / Webcam, select the device, then set its resolution and frame rate. Camera mode starts with No microphone; choose a Microphone / Input to add sound. The live camera preview appears after starting.

Syphon

Enable Syphon output in the sending Mac app, choose Syphon (texture sharing), and select its sender. Syphon supplies video; select audio separately. Spout2 is the Windows source option.

3. Choose what people hear

Open Show advanced settings → Audio Source. App and system audio use native macOS capture; a virtual audio cable is not required for these modes.

Add your voice over app audio

  1. Select your microphone in Microphone / Input.
  2. Enable Also add microphone/input in advanced settings.
  3. Use headphones if you listen to your own viewer, to avoid feedback.

Mute / Unmute affects the microphone; app audio keeps playing.

Keep the default Opus audio for normal VDO.Ninja viewing. Use the generated viewer link so the receiver gets the selected audio-channel settings.

4. Pick an encoder

Apple VideoToolbox

Hardware H.264 encoding on Apple Silicon. Start here for window or game capture to leave more CPU capacity for the source app.

x264 software

Select H.264 with Software (x264 / VP9 / AV1). This uses the CPU and is useful when comparing a hardware-encoder problem. Lower resolution or FPS if the Mac cannot keep up.

Auto tries hardware and then software. The software menu lists other codecs, but H.264 is the straightforward starting point for this guide.

1080p60 is not yet production-qualified across machines and workloads. Start at 720p30, verify received video and audio, and increase settings gradually. See the qualification record for measured results and remaining limits.

5. Use a room or OBS

VDO.Ninja rooms

  1. Paste your director’s publishing URL, or enter the Room in advanced settings.
  2. Match the room’s password. Add a Label if your director asks for one.
Room quality and director control

Room quality can send a smaller preview to directors and guests while scene viewers receive a higher-quality stream.

Enable director control only for remote changes. Share its control token only with your trusted director.

OBS

  1. In OBS, add a Browser Source and paste the viewer link copied from Game Capture.
  2. Set its width and height to match your stream.
  3. Check picture and sound. Close duplicate viewers to avoid hearing the same feed twice.
WHIP, SRT, RTMP and other destinations
  1. Open Show advanced settings → Output and choose the destination.
  2. Enter the service’s publishing endpoint and credentials.
  3. Follow that service’s receiver instructions. VDO.Ninja room controls and viewer links apply only to VDO.Ninja output.

Trusted remote RTMPS and broader service compatibility remain part of beta qualification.

Troubleshooting

My window is missing, or the preview is blank
  1. Check Screen Recording permission. Reopen Game Capture if macOS asked you to.
  2. Restore the source window if it is minimized or hidden.
  3. Click Refresh, clear the source filter, and select the window again.
  4. If the source app closed, choose an available source before starting again.
Video pauses when I minimize the source

Restore the source window. The Mac app pauses video delivery while the captured window is suspended and resumes when fresh frames return; audio may continue. Keep the source visible during a stream.

I have picture but no sound
  1. Check Audio Source, the selected microphone, and mute state. Selected app audio needs Window capture.
  2. Check the source app’s volume and the viewer’s playback and volume controls.
  3. Allow audio/microphone access in macOS if needed, then stop and start the stream.
  4. For a microphone-off warning, reconnect or reselect the input, then restart streaming.
The camera or microphone is unavailable
  1. Check its Privacy & Security permission and connect the device.
  2. Close other software using it. Click Refresh and select it again.
  3. After granting permission, try Go Live again.

Hotplug and busy-device coverage is still incomplete in this beta.

The stream stutters or falls behind
  1. Stop streaming. Try H.264 / Apple VideoToolbox / 720p30.
  2. Close unnecessary viewers on the publishing Mac and check upload bandwidth.
  3. Start again and compare playback on another machine.
macOS says the app is damaged or cannot be verified
  1. Download a fresh copy from the official Mac release.
  2. Compare its checksum with the release’s checksum file. Keep macOS security checks enabled.
  3. If it still fails, report the exact message and your macOS version.

Updates and support

  1. Download the new beta from the Mac release page.
  2. Stop streaming and quit Game Capture.
  3. Replace the app in Applications.

The stable update check excludes betas. This beta reports version 0.2.65; include the ZIP’s beta number in issue reports.

What to include in a problem report
  • Your Mac model, macOS version, and beta download.
  • Video/audio source, encoder, and steps that reproduce the issue.
  • Logs from Help → Open Log Folder. Remove credentials before sharing.
